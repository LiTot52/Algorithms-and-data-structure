## Теоретическое обоснование

**Анализ сложности** - это математический способ оценки эффективности алгоритма в зависимости от размера входных данных. Выделяют временную сложность (сколько выполняется) и пространственную (сколько памяти занимает). 

**О-нотация (Big O)** описывает асимптотическое поведение функции при стремлении аргумента к бесконечности. Она показывает, как быстро растёт время работы алгоритма при увеличении входных данных, отбрасывая константы и младшие члены.

Основные классы сложности:
*   **O(1)** - константная (доступ по индексу).
*   **O(log n)** - логарифмическая (бинарный поиск).
*   **O(n)** - линейная (линейный поиск, сумма элементов).
*   **O(n log n)** - линейно-логарифмическая (быстрая сортировка, сортировка слиянием).
*   **O(n²)** - квадратичная (пузырьковая сортировка, вложенные циклы).
*   **O(2^n)** - экспоненциальная (рекурсивное вычисление чисел Фибоначчи).

**Шаблоны (Templates)** позволяют писать обобщенный код, который работает с разными типами данных, избегая дублирования кода (в отличие от перегрузки функций). Шаблоны бывают функциями и классами.
